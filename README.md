# Kalman-Filter-for-SoC-Estimation
State of Charge (SoC) Estimation algortihm for a single cell. The algortihm uses Resistive cell model and Extended Kalman Filter to linearlize the OCV-SoC curve.  

I have also designed a PCB using eagle, which measures the cell-voltage and cell-current and also designed analog accmulator which acts as a coulomb counter. In the future, I want to integrate the analog coulomb counter int the SoC estimation algorithm.
